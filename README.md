# Домашний диспетчер еды

Семейный MVP-планировщик меню, остатков, запасов и покупок.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверки

```bash
npm run lint
npm run build
```
